# Mountain Climber (`mountain_climber`) — Rive 7.3 HD 3D Procedural Animation

60 FPS, 16:9 (`640x360`, `FLOOR = 300.0`) procedural Rive 7.3 animation for **Mountain Climber** (`assets/animations/mountain_climber.riv`), featuring a 3/4 high-plank athlete driving alternating knees toward the chest with exact 2-bone inverse kinematics and dynamic muscle activation on the **Rectus femoris / Iliopsoas (hip flexors)**, **Vastus lateralis & Vastus medialis (quadriceps)**, **Rectus abdominis & External obliques**, and **Serratus anterior / Anterior deltoid**.
