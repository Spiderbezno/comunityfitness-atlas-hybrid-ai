# Leg Press (`leg_press`) — Rive 7.3 HD 3D Procedural Animation

60 FPS, 16:9 (`640x360`, `FLOOR = 300.0`) procedural Rive 7.3 animation for **Leg Press** (`assets/animations/leg_press.riv`), featuring a 45-degree Plate-Loaded Leg Press Machine with exact closed-chain two-bone inverse kinematics (`HIP -> KNEE -> ANKLE` on the `-36°` sled guide rails) and dynamic muscle activation on the **Quadriceps femoris** (`Rectus femoris`, `Vastus lateralis`, `Vastus medialis / VMO`), **Gluteus maximus**, and **Hamstrings / Gastrocnemius**.

## Build & Publish
```bash
python3 rive_animations/leg_press/gen_leg_press.py --publish
```
