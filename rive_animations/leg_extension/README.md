# Seated Leg Extension (`leg_extension`) — Procedural Rive 7.3 Project

60 FPS, 16:9 (`640x360`, `FLOOR = 300.0`) HD 3D Rive animation for **Leg Extension** (`id: "leg_extension"`), using the canonical 3/4 front-left CommunityFitness mannequin seated in a commercial Leg Extension Machine.

## Target Muscles Highlighted
- **Rectus femoris** (Primary — central anterior head of the quadriceps femoris)
- **Vastus lateralis** (Primary — outer lateral sweep of the quadriceps femoris)
- **Vastus medialis / VMO** (Primary — medial teardrop head above the knee)

## Build & Publish
```bash
python3 gen_leg_extension.py --publish
```
