# Seated Leg Curl (`leg_curl`) — Procedural Rive 7.3 Project

60 FPS, 16:9 (`640x360`, `FLOOR = 300.0`) HD 3D Rive animation for **Leg Curl** (`id: "leg_curl"`), using the canonical 3/4 front-left CommunityFitness mannequin seated in a commercial Seated Leg Curl Machine.

## Target Muscles Highlighted
- **Hamstrings** (`Biceps femoris`, `Semitendinosus`, `Semimembranosus` — Primary)
- **Gastrocnemius** (`Medial & Lateral Calf Heads` — Secondary)
- **Gracilis / Sartorius Medial Knee-Flexor Insertion** (Secondary)

## Build & Publish
```bash
python3 gen_leg_curl.py --publish
```
