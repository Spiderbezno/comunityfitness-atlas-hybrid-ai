# Dumbbell Lunge (`lunge`) — Rive 7.3 HD 3D Procedural Animation

60 FPS, 16:9 (`640x360`, `FLOOR = 300.0`) procedural Rive 7.3 animation for **Dumbbell Lunge** (`assets/animations/lunge.riv`), featuring exact two-bone inverse kinematics for both the stepping front leg and the pivoting rear leg, cast-iron dumbbells in neutral hammer grip, and dynamic muscle activation on all 8 reference target muscles (**Rectus femoris**, **Vastus lateralis**, **Vastus medialis**, **Gluteus maximus**, **Adductor magnus**, **Hamstrings**, **Gastrocnemius**, and **Soleus**).

## Build & Publish
```bash
python3 rive_animations/lunge/gen_lunge.py --publish
```
